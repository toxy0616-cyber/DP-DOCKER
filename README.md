# DP-DOCKER
基于ollama 本地部署的ai智能医生
## 项目简介
本项目基于 Ollama 本地部署，打造智能AI医生应用。

## 主要功能 / Features

- 本地智能医疗问诊（Local AI-powered medical consultation）
- 支持医疗知识问答（Medical knowledge Q&A support）
- 多轮对话和上下文记忆（Multi-turn conversation & context memory）
- 用户数据本地化存储，隐私保护（Local user data storage with privacy protection）
- 可自定义扩展医学知识库（Customizable medical knowledge base）
- 简单可用的 Web UI（Simple and user-friendly Web UI）
